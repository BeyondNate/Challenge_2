# Challenge 1 — Pipeline de Machine Learning

**Caso Tipo A: Minería de Asteroides**

## Descripción

Proyecto académico que integra algoritmos de búsqueda y Machine Learning para simular la exploración de un asteroide, la recolección de muestras y la predicción de su contenido mineral sintético.

1. Abre el notebook correspondiente desde GitHub.

3. Ejecuta las celdas en orden.
4. Revisa los resultados, las métricas y las visualizaciones.

## Limitaciones

Los datos son sintéticos y sirven para demostrar los procedimientos computacionales. Las predicciones no constituyen estimaciones de contenido mineral real de asteroides.
